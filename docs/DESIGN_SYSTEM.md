# Design System

## Design Goal

The UI must remain visually consistent with the provided client references.

The design language is premium, modern, elegant and minimal.

Never redesign the interface from scratch.

Every page should feel like part of the same application.

---

# Overall Style

Dark Theme Only.

Use luxury educational branding.

The application should feel professional and trustworthy.

Avoid colorful or playful designs.

Avoid gradients unless already used in the reference.

---

# Border Radius

Large Cards:
18px

Inputs:
14px

Buttons:
16px

Small Components:
12px

---

# Shadows

Very soft shadows.

Avoid heavy shadows.

Cards should rely mostly on contrast instead of shadow.

---

# Typography

Arabic First.

Use modern Arabic fonts.

Examples:

- Cairo
- IBM Plex Sans Arabic
- Alexandria

Use medium and bold weights.

Avoid thin fonts.

---

# Buttons

Buttons should:

- Gold background
- Black text
- Rounded corners
- Large height
- Full width when primary action

Never use blue buttons.

---

# Cards

Cards should:

Dark background

Thin border

Rounded corners

Padding between 16px and 24px

Small hover animation only

---

# Icons

Use outlined icons.

Prefer Lucide Icons.

Icons should be Gold.

---

# Navigation

Bottom Navigation.

Dark background.

Active item:

Gold icon

Gold text

Inactive:

Gray

---

# Inputs

Dark background.

Gold icon.

Light border.

Rounded.

Large touch area.

---

# Animations

Fast.

Simple.

Professional.

No excessive motion.

---

# Images

Teacher images should have:

Transparent background if possible.

Professional pose.

Consistent crop.

---

# Spacing

Generous spacing.

Never crowd components.

Use an 8px spacing system.

---

# Responsive

Mobile First.

Tablet supported.

Desktop supported.

---

# Pages must keep the same visual identity

- Home
- Teachers
- Subjects
- Booking
- Notifications
- Contact
- Dashboard

Every page should look like it belongs to the same application.

---

# Strict Rules

DO NOT

❌ Use Material Design style.

❌ Use bright colors.

❌ Use random gradients.

❌ Change the navigation style.

❌ Change button styles.

❌ Change typography.

❌ Mix multiple UI styles.

Always follow the reference images.
